# Huewy content assets

Rendered social carousels, served publicly so the scheduler (Metricool) can fetch them.
Not part of the website. This branch never deploys (see vercel.json).

Layout: social/<ISO week>/<instagram|tiktok>/<date>_<post>-<slide>.png
- instagram: 1080x1350 (4:5)
- tiktok: 1080x1920 (9:16)
